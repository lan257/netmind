# Tool 修改流程

1. 读取目标 Tool 的 `tool_definition.json`、`run.py` 和 `tool.md`。
2. 确认当前只修改这一个 Tool 文件夹。
3. 明确用户要修改的是实现逻辑、参数、权限、文档、分类还是标签。
4. 分析变更影响范围，列出需要同步的文件。
5. 修改 `run.py`，保证真实执行逻辑与需求一致。
6. 修改 `tool_definition.json`，同步参数、权限、脚本路径、分类和标签。
7. 修改 `tool.md`，同步功能说明、参数表、返回值、示例和维护说明。
8. 写入较长的 `run.py` 或 `tool.md` 时，使用 `long_text_line_modifier_guide` 拆成多次批量写入。
9. 校验当前 Tool 文件夹内的定义、实现和文档一致，必要时运行相关单元测试或最小调用验证。
10. 输出更新摘要、验证结果和剩余风险。
