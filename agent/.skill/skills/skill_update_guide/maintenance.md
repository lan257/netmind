# 维护说明

- 更新 Skill 时只维护一个文件夹；文件夹内的 `skill_definition.json` 是定义来源。
- `workflow.md` 不应保存脚本代码或 JSON 配置，只保存纯文本流程。
- 如果用户实际要求新增可执行能力，应改为创建或修改 Tool。
- 每次修改后校验 Skill 文件夹中不存在 `run.py`。
- 列表和绑定不在基本流程中手改。
- 长文本写入使用 `long_text_line_modifier_guide` 拆块，避免单次写入超出限制。
- 新增标签或分类时避免逗号进入单个标签值，保持列表序列化稳定。
- 修改触发条件时注意与 Tool 创建、Tool 修改指南的触发范围不要重叠。
