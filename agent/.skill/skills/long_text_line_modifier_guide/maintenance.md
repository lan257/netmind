# 维护说明

- 本 Skill 只描述如何批量使用已有 Tool，不得加入 `run.py`、权限字段或 Tool 执行参数。
- 本 Skill 依赖 `line_reader` 的行号读取能力和 `line_modifier` 的局部替换语义；修改任一 Tool 合同时同步检查这里的流程。
- `40` 行和 `4000` 字符来自 `line_modifier` 当前策略；策略变化后要同步更新定义提示、拆块规则和错误处理说明。
- 批量调用必须区分“行号可累计”与“行号会漂移”两类场景，不要把需要重读锚点的修改伪装成一次性确定调用。
- 维护时至少复核三类场景：大段替换按底部到顶部拆块、文件尾追加按累计行数追加、局部插入后分批重读后续锚点。
